# DPS Meter Implementation Plan (event-driven via inline hook)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Pivot note**: This plan was rewritten on 2026-05-08 after RE pivoted from
> HP-delta polling to inline hook on `D2Common::STATLIST_SetUnitStat`. The
> new architecture works in both SP and MP and gives absolute damage numbers
> via MonStats `wMaxHP[difficulty]` scaling. See
> [`docs/dps-meter-reverse-engineering.md`](../../dps-meter-reverse-engineering.md)
> for full RE record.

**Goal:** Build a live DPS overlay (rolling 5 s DPS + session Peak + session Total) inside the existing in-game overlay window, driven by an inline hook on `D2Common.dll + 0x3A740` (`STATLIST_SetUnitStat`) that captures every monster HP write, scales via MonStats `wMaxHP`, and feeds a scanner-side rolling-window accumulator. **Works in SP and MP.**

**Architecture summary:**
- Game thread executes `Ord10887` → our trampoline intercepts → filters (statId=6, monster, wild, value<old) → reads old HP inline → pushes event to shared-memory ring buffer → resumes original prologue
- Scanner thread drains ring buffer per tick → computes `damage = (delta_raw / 32768) × max_hp` → updates rolling-window meter → emits `dps-update` event
- Frontend Svelte component renders three numbers in draggable overlay panel

**Tech Stack:** Rust + Tauri v2 + `windows` crate (backend, including `VirtualAllocEx`/`WriteProcessMemory` already used for existing GetStringById injection); Svelte 5 (runes) + TypeScript + vanilla CSS (frontend); pnpm.

**Spec:** `docs/superpowers/specs/2026-05-07-dps-meter-design.md`

## Task 2: TDD pure-Rust `DpsMeter`

**Files:** Create `src-tauri/src/dps_meter.rs`, modify `src-tauri/src/main.rs`

The accumulator is pure data — no Win32, no memory access. Drives logic via `ingest()` (called by ring drainer) and `snapshot()` (called by scanner emit). Tracks both **damage** (DPS rolling, peak, total) and **kills** (kpm rolling, total).

The hook encodes `is_kill` in **bit 31 of `delta_raw`** — server sets HP to 0 on kill (`new_value == 0`), trampoline ORs `0x8000_0000` into `delta_raw` before pushing to the ring. Scanner-side decodes on `ingest`.

//! Pure-data DPS accumulator. The hook drains events from the ring
//! buffer into `ingest`; the scanner emit polls `snapshot`.
//!
//! Tracks both damage (DPS rolling / peak / cumulative total) and

use std::collections::VecDeque;

pub const WINDOW_SECONDS: f32 = 5.0;
const WINDOW_MS: u64 = 5_000;
const KILL_FLAG: u32 = 0x8000_0000;
const DELTA_MASK: u32 = 0x7FFF_FFFF;

struct Event {

```rust
/// Test helper — direct insert with explicit kill flag, no scaling.
#[cfg(test)]
fn ingest_test(&mut self, ts_ms: u64, damage: u32, is_kill: bool) {
    self.events.push_back(Event { ts_ms, damage, is_kill });
    self.session_total += damage as u64;
    if is_kill { self.session_kills += 1; }
}

/// Real drain — scales raw delta by monster's MonStats max HP, decodes
/// kill flag from bit 31. The trampoline encodes:
///   bit 31: is_kill
///   bits 0-30: actual delta (server-protocol max is 32768 ⇒ fits 16 bits)
pub fn ingest(&mut self, ts_ms: u64, delta_raw_with_flag: u32, max_hp: u16) {
    let is_kill = (delta_raw_with_flag & KILL_FLAG) != 0;
    let delta_raw = delta_raw_with_flag & DELTA_MASK;
    let damage = ((delta_raw as u64).saturating_mul(max_hp as u64) / 32768) as u32;
    if damage == 0 && !is_kill { return; }
    self.events.push_back(Event { ts_ms, damage, is_kill });
    self.session_total += damage as u64;
    if is_kill { self.session_kills += 1; }
}

pub fn snapshot(&mut self, now_ms: u64) -> DpsSnapshot {
    let cutoff = now_ms.saturating_sub(WINDOW_MS);
    while let Some(e) = self.events.front() {
        if e.ts_ms < cutoff { self.events.pop_front(); } else { break; }
    }
    let window_dmg: u64 = self.events.iter().map(|e| e.damage as u64).sum();
    let window_kills: u32 = self.events.iter().filter(|e| e.is_kill).count() as u32;
    let dps = window_dmg as f32 / WINDOW_SECONDS;
    let kpm = (window_kills as f32) * (60.0 / WINDOW_SECONDS);
    if dps > self.session_peak { self.session_peak = dps; }
    DpsSnapshot {
        dps,
        kpm,
        peak: self.session_peak,
        total: self.session_total,
        kills: self.session_kills,
        in_session: !self.events.is_empty() || self.session_total > 0 || self.session_kills > 0,
    }
}
```

// src/lib/format-dps.ts

export function formatDps(value: number): string {
    if (!Number.isFinite(value) || value < 0) return '0';
    if (value < 1000) return Math.round(value).toString();

    const units = ['', 'k', 'M', 'B'];
    let unitIdx = 0;
    let scaled = value;
    while (scaled >= 1000 && unitIdx < units.length - 1) {
        scaled /= 1000;
        unitIdx++;
    }
    // 3 significant figures
    let str: string;
    if (scaled >= 100) str = scaled.toFixed(0);
    else if (scaled >= 10) str = scaled.toFixed(1);
    else str = scaled.toFixed(2);
    return str + units[unitIdx];
}

- [ ] **Step 1: Implement `build()` step-by-step**

Build a `Vec<u8>` by appending bytes for each instruction in order. Track offsets for jump targets. Resolve jumps after layout is known.

Pseudo-Rust:

```rust
pub fn build(p: &BuildParams) -> TrampolineBlob {
    let mut buf = Vec::with_capacity(0x400);
    let mut fixups: Vec<(usize, JumpTarget)> = Vec::new();

    let trampoline_offset = buf.len();

    // --- prologue: save state ---
    buf.push(0x9C); // pushfd
    buf.push(0x60); // pushad

    // --- read args ---
    push_bytes(&mut buf, &[0x8B, 0x44, 0x24, 0x28]); // mov eax, [esp+0x28]  ; pUnit
    push_bytes(&mut buf, &[0x8B, 0x4C, 0x24, 0x2C]); // mov ecx, [esp+0x2C]  ; statId
    push_bytes(&mut buf, &[0x8B, 0x54, 0x24, 0x30]); // mov edx, [esp+0x30]  ; value

    // --- filter: statId == 6 ---
    push_bytes(&mut buf, &[0x83, 0xF9, 0x06]);  // cmp ecx, 6
    let jne_restore_1 = emit_short_jne(&mut buf);

    // --- pUnit non-null ---
    push_bytes(&mut buf, &[0x85, 0xC0]);        // test eax, eax
    let jz_restore_1 = emit_short_jz(&mut buf);

    // --- pUnit.dwType == MONSTER (1) ---
    push_bytes(&mut buf, &[0x83, 0x38, 0x01]);  // cmp dword [eax], 1
    let jne_restore_2 = emit_short_jne(&mut buf);

    // ... continue per spec ...

    // --- ring push: call helper ---
    push_bytes(&mut buf, &[0x53]);              // push ebx (delta_raw)
    push_bytes(&mut buf, &[0x56]);              // push esi (pMonStatsRecord)
    push_bytes(&mut buf, &[0x50]);              // push eax (pUnit)
    let call_helper_at = emit_call_rel32(&mut buf);
    fixups.push((call_helper_at, JumpTarget::Helper));
    push_bytes(&mut buf, &[0x83, 0xC4, 0x0C]);  // add esp, 0xC

    // --- restore label ---
    let restore_pos = buf.len();
    resolve_short_jumps(&mut buf, &[jne_restore_1, jz_restore_1, jne_restore_2, /*...*/], restore_pos);

    push_bytes(&mut buf, &[0x61]);              // popad
    push_bytes(&mut buf, &[0x9D]);              // popfd

    // --- execute saved 5 bytes ---
    push_bytes(&mut buf, &[0x8B, 0x44, 0x24, 0x0C]); // mov eax, [esp+0xC]
    push_bytes(&mut buf, &[0x53]);                    // push ebx

    // --- jmp back to Ord10887+5 ---
    let jmp_resume_at = emit_jmp_rel32(&mut buf);
    fixups.push((jmp_resume_at, JumpTarget::Resume));

    // ──────────────────────────────────────────────────────
    // HELPER: ring_push(pUnit, pMonStatsRecord, delta_raw)
    //   Reads difficulty, max_hp, unit_id, ts_ms (GetTickCount)
    //   Writes to ring slot at head, increments head atomically.
    // ──────────────────────────────────────────────────────
    let helper_offset = buf.len();
    // ... emit helper ...

    // ──────────────────────────────────────────────────────
    // RING BUFFER region (zeroed)
    // ──────────────────────────────────────────────────────
    let ring_offset = align_up(buf.len(), 16);
    while buf.len() < ring_offset { buf.push(0); }
    // header: head=0, tail=0, capacity, _pad
    buf.extend_from_slice(&0u32.to_le_bytes());
    buf.extend_from_slice(&0u32.to_le_bytes());
    buf.extend_from_slice(&p.ring_capacity.to_le_bytes());
    buf.extend_from_slice(&0u32.to_le_bytes());
    // slot array
    let slots_size = (p.ring_capacity as usize) * 16;
    buf.resize(buf.len() + slots_size, 0);

    // ──────────────────────────────────────────────────────
    // RESOLVE FIXUPS
    // ──────────────────────────────────────────────────────
    for (at, target) in fixups {
        let abs_target = match target {
            JumpTarget::Resume => p.ord10887_resume,
            JumpTarget::Helper => p.blob_base + helper_offset,
        };
        let from = p.blob_base + at + 4; // EIP after the rel32 dword
        let rel: i32 = (abs_target as i64 - from as i64) as i32;
        buf[at..at+4].copy_from_slice(&rel.to_le_bytes());
    }

    TrampolineBlob {
        bytes: buf,
        trampoline_offset,
        helper_offset,
        ring_offset,
    }
}
```

- [ ] **Step 2: Helper subroutine — most complex part**

The helper reads:
- `difficulty` from `[difficulty_addr]` (u32, 0/1/2)
- `max_hp = u16 [pMonStatsRecord + 0xB0 + difficulty * 2]`
- `unit_id = u32 [pUnit + 0x0C]`
- `ts_ms = GetTickCount()` (call `KERNEL32.GetTickCount`)

Then atomic ring write:
```asm
helper:
    push ebp
    mov ebp, esp
    push ebx
    push esi
    push edi

    ; args: [ebp+8]=pUnit, [ebp+0xC]=pMonStatsRecord, [ebp+0x10]=delta_raw

    ; difficulty * 2 → ebx (as offset into wMaxHP[3])
    mov eax, [DIFFICULTY_ADDR]
    add eax, 0x58           ; 0xB0 / 2 = 0x58 if reading as words; but easier:
    ; max_hp = u16 [pMonStatsRecord + 0xB0 + diff*2]
    mov ecx, [DIFFICULTY_ADDR]
    shl ecx, 1              ; diff * 2
    mov esi, [ebp+0xC]      ; pMonStatsRecord
    movzx eax, word [esi+ecx+0xB0]
    mov [ebp-0x4], eax      ; save max_hp on local stack temporarily

    ; unit_id
    mov esi, [ebp+8]
    mov edi, [esi+0x0C]     ; edi = unit_id

    ; ts_ms via GetTickCount
    call [GET_TICK_COUNT_IAT]   ; or import a static address

    ; Now: eax = ts_ms, edi = unit_id, [ebp-4] = max_hp, [ebp+0x10] = delta_raw
    
    ; ring_addr is a constant (blob_base + ring_offset)
    mov ecx, RING_ADDR       ; capacity at ecx+8
    mov ebx, [ecx+0x08]      ; capacity
    dec ebx                  ; mask
    
    ; atomic head++ via lock xadd
    mov esi, 1
    lock xadd [ecx], esi     ; esi = old head
    and esi, ebx             ; slot index
    
    ; slot ptr = ring + 0x10 + esi*0x10
    shl esi, 4
    add esi, ecx
    add esi, 0x10            ; esi = slot ptr
    
    mov [esi+0x00], eax      ; ts_ms
    mov [esi+0x04], edi      ; unit_id
    mov ebx, [ebp+0x10]      ; delta_raw
    mov [esi+0x08], ebx      ; delta_raw
    mov ebx, [ebp-0x4]       ; max_hp
    mov [esi+0x0C], ebx      ; max_hp (low word) + pad

    pop edi
    pop esi
    pop ebx
    leave
    ret 0xC                  ; cdecl, but caller cleans... actually we used 'add esp, 0xC' in trampoline
                             ; so use plain `ret 0` and let caller clean. Pick one convention and stick.
```

Pick `__cdecl` (caller cleans) for simplicity → trampoline already does `add esp, 0xC` after the call. Helper just `ret`.

`GetTickCount` resolution: we need to either:
- (A) Find KERNEL32!GetTickCount via the Rust side at install time (`GetProcAddress`), pass as a `BuildParams` field
- (B) Walk the IAT in D2Client.dll for the GetTickCount slot
- (A) is simpler.

```rust
pub fn drain(&mut self) -> Vec<crate::dps_hook::HookEvent> {
    let mut events = Vec::new();

    // Read header: head, tail, capacity
    let mut header = [0u8; HEADER_SIZE];
    if read_process_memory(self.process, self.ring_addr, &mut header).is_err() {
        return events;
    }
    let head = u32::from_le_bytes(header[0..4].try_into().unwrap());
    let capacity = u32::from_le_bytes(header[8..12].try_into().unwrap());

    // Bound check
    if capacity == 0 || (capacity & (capacity - 1)) != 0 || capacity > 0x10000 {
        return events; // sanity
    }

    let pending = head.wrapping_sub(self.tail);
    if pending == 0 { return events; }
    // Cap to capacity (overflow protection if writer raced way ahead)
    let to_read = pending.min(capacity);

    for _ in 0..to_read {
        let slot_idx = self.tail & (capacity - 1);
        let slot_addr = self.ring_addr + HEADER_SIZE + (slot_idx as usize) * SLOT_SIZE;

        let mut slot = [0u8; SLOT_SIZE];
        if read_process_memory(self.process, slot_addr, &mut slot).is_err() {
            break;
        }
        let ts_ms = u32::from_le_bytes(slot[0..4].try_into().unwrap()) as u64;
        let unit_id = u32::from_le_bytes(slot[4..8].try_into().unwrap());
        let delta_raw = u32::from_le_bytes(slot[8..12].try_into().unwrap());
        let max_hp = u16::from_le_bytes(slot[12..14].try_into().unwrap());

        events.push(crate::dps_hook::HookEvent {
            ts_ms,
            unit_id,
            delta_raw,
            max_hp,
        });

        self.tail = self.tail.wrapping_add(1);
    }

    events
}
```

            meter.reset();

## Acceptance criteria (v1)

- Hook installs successfully on attach in both SP and MP.
- DPS reading is non-zero during active combat.
- Kills/min reading is non-zero when monsters die.
- Total accumulates correctly across sustained combat.
- Kills (cumulative) matches actual kill count (verifiable on small mob groups).
- Peak tracks max DPS over the session.
- Session auto-resets on area change (waypoint or walk).
- No crashes during 10-minute soak test.
- Game performance unaffected (no visible FPS drop).
- DoT damage limitation documented in tooltip.
